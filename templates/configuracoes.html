Verificar Dominio no SES

Para enviar e-mails com @asamarketingevendas.com.br, o dominio precisa ser verificado. Execute os comandos abaixo no terminal.

# 1. Verificar o dominio
aws ses verify-domain-identity --domain asamarketingevendas.com.br --region sa-east-1

# 2. Verificar email especifico (alternativa)
aws ses verify-email-identity --email-address contato@asamarketingevendas.com.br --region sa-east-1

# 3. Ver status das identidades
aws ses list-identities --region sa-east-1
Registros DNS Necessarios

Adicione esses registros no painel DNS do seu dominio (Registro.br, Cloudflare, etc.):

SPF
Tipo: TXT
Nome: @
Valor: v=spf1 include:amazonses.com ~all
DKIM
Execute para obter as chaves DKIM:
aws ses get-identity-dkim-attributes
--identities asamarketingevendas.com.br
--region sa-east-1
Adicione os 3 registros CNAME que o comando retornar.
DMARC
Tipo: TXT
Nome: _dmarc
Valor: v=DMARC1; p=none; rua=mailto:dmarc@asamarketingevendas.com.br
Sair do Sandbox do SES

No Sandbox voce so pode enviar para e-mails verificados. Para enviar em producao:

  1. Acesse o Console AWS → Amazon SES
  2. Clique em "Request production access"
  3. Preencha: tipo de uso = Marketing
  4. Descreva: envio de campanhas de email marketing
  5. Website: asamarketingevendas.com.br
  6. Aguarde aprovacao (geralmente 24h)

Alerta de Faturamento AWS

Configure um alerta para ser avisado sobre qualquer cobranca:

# Criar SNS topic para alertas
aws sns create-topic --name alerta-faturamento --region us-east-1

# Subscrever seu e-mail (substitua ARN e email)
aws sns subscribe --topic-arn SEU_ARN_AQUI \
  --protocol email \
  --notification-endpoint contato@asamarketingevendas.com.br

# Criar alarme de billing (qualquer valor > $0.01)
aws cloudwatch put-metric-alarm \
  --alarm-name "aws-custo-qualquer" \
  --metric-name EstimatedCharges \
  --namespace AWS/Billing \
  --statistic Maximum \
  --period 86400 \
  --threshold 0.01 \
  --comparison-operator GreaterThanThreshold \
  --dimensions Name=Currency,Value=USD \
  --evaluation-periods 1 \
  --alarm-actions SEU_ARN_AQUI \
  --region us-east-1
Billing Alarms so funcionam na regiao us-east-1.
